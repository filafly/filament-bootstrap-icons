# Changelog

## v1.0.0 - 2026-11-15

- First release: Bootstrap Icons for every Filament 4 and 5 UI icon alias (223 in Filament 5.11), registered with `BootstrapIcons::make()`.
- Regular (default) and fill styles: `->fill()`, plus per-alias and per-icon style overrides.
- `Bootstrap` enum with all 2,078 icons from davidhsianturi/blade-bootstrap-icons 2.x.
