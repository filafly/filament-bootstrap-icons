# CLAUDE.md

Bootstrap Icons pack for Filament 4 and 5, built on the filafly/filament-icons core.

- `src/BootstrapIcons.php`: the plugin. `$iconMap` maps every Filament icon alias to a `Bootstrap` case, using the regular case. Keys are alias strings, not `*IconAlias` constants, because some constants only exist in later 4.x releases. `$currentStyle` defaults to Regular so style overrides work without a global style.
- `src/Enums/Bootstrap.php`: generated by `php bin/generate-icon-cases.php` from davidhsianturi/blade-bootstrap-icons (Blade prefix `bi`). Don't edit by hand.
- `src/Enums/BootstrapStyle.php`: Regular (no suffix) and Fill (`-fill`).

Commands: `composer test` (PHPUnit + Testbench), `vendor/bin/pint`. The ship gate runs `npm test`, which runs composer update then PHPUnit.

`BootstrapIconsTest::test_every_filament_alias_is_mapped` fails when a new Filament release adds an alias: map it in `$iconMap`.
